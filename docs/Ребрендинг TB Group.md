# Ребрендинг сайта TB Group

> [!info] Назначение файла
> Долгосрочная память проекта. Здесь фиксируется контекст ребрендинга, решения и план,
> чтобы не пересказывать всё заново в каждой сессии. Обновлять по мере продвижения.

## Контекст / задача

Сайт (`tbgroup.kz`) **не соответствует бренд-буку**. Сейчас это стандартный «AI corporate blue»
шаблон: с брендом совпадает только название. Цель — привести сайт в полное соответствие
[[#Бренд-бук — суть|бренд-буку TB Group v1.0]] без изменения бизнес-логики и структуры.

Бренд-бук: `BrandBook/brand book TB Group.pdf` (33 стр., растровые страницы).

## Бриф заказчика (получен 2026-07-12)

Роль: Senior Product Designer / Art Director / Frontend UX Architect. Ключевые требования:

- **Уровень результата:** современная tech-компания уровня Stripe / Linear / Vercel / Anthropic /
  Framer / Clerk — но 100% в фирменном стиле TB Group.
- **Бренд-бук использовать буквально:** палитра, градиент, геометрия, линии, иллюстрации,
  паттерны, формы, настроение, пропорции, композиция.
- **Запрещено:** типовые AI-секции/карточки/Hero/кнопки/иконки/градиенты, круглые блобы,
  стеклянные карточки (glass), неоновые эффекты, шаблоны Framer/Tailwind UI, случайный Heroicons.
- **Hero:** полностью переработать — динамическая композиция, крупная типографика, слои,
  геометрические линии, градиентные элементы, объём, движение, цифровая сетка.
- **Deliverables:** полная дизайн-система — цветовые роли (Primary…Disabled), типографическая
  шкала (Display…Label), UI Kit (кнопки, карточки, формы, табы, modal, badge, timeline, FAQ,
  header/footer, breadcrumbs…), стиль иконок, спецификация анимаций (hover/scroll/reveal/
  parallax…), 3+ варианта фирменного фона, редизайн всех секций, responsive (desktop/laptop/
  tablet/mobile), 8pt grid, whitespace, рекомендации разработчикам.
- **Процесс:** двухэтапный — сначала полный UX/UI-аудит, потом дизайн-система и редизайн
  (согласовано, см. процесс ниже).
- **Критерий приёмки:** сайт мгновенно опознаётся как TB Group, а не AI-шаблон.

## Решения (согласовано с заказчиком)

| Вопрос | Решение |
|---|---|
| Объём | Полный ребрендинг |
| Michroma | Self-host (nginx / `client/public/fonts` + `@font-face`) |
| Кириллица в заголовках | Michroma только латиница («TB GROUP», цифры, англ. лейблы) — кириллицу НЕ поддерживает (проверено). Display-шрифт кириллицы **НЕ зафиксирован**: на этапе B конкурс минимум из 3 кандидатов (Unbounded, Inter, Manrope/Onest или близкие) с визуальным сравнением и аргументацией |
| Тёмная тема | Обе темы. Приоритет **НЕ зафиксирован**: на этапе B две полноценные концепции — Light-first и Dark-first — решение после визуального сравнения |
| Формат концепции | **HTML-стайлгайд (артефакт) + markdown-документ в docs/** — утверждение глазами до кода |
| Логотип | Извлекаем из PDF (растр для навбара/футера), знак пересобрать в SVG для favicon/hero |
| Иконки | База Lucide + единый градиентный stroke (purple→magenta→orange), ключевые иконки услуг — перерисовать. Без случайного набора |

## Принципы концепции (зафиксированы в обсуждении)

1. **Правило 90/10:** ~90% поверхности нейтральны (белый/индиго, тонкие линии, воздух),
   бренд живёт в ~10% — но безошибочно узнаваемых (градиентные акценты, орбитальная графика,
   точечные паттерны, лого). Так яркий бренд-бук совмещается со сдержанностью уровня Stripe.
2. **Экстраполяция с трассировкой:** в бренд-буке нет UI (он печатно-сувенирный). Каждое
   UI-решение должно трассироваться к конкретной странице бренд-бука («восходящая диагональ
   2pt» с бейджей → hover карточек; охранные поля лого → отступы; точечный паттерн → фоны).
3. **Свечение — ограниченно:** только тонкая градиентная подсветка узлов орбитальной графики
   (как светящийся узел на карте Казахстана в бренд-буке). Никакого neon-glow у кнопок/текста.
4. **Анимации усиливают, не отвлекают.**

## Процесс (три этапа)

- **Этап A — формальный UX/UI-аудит** (не начат, ждём команду): постранично все 8 страниц
  (Home, ServicePage ×3, Cases, CaseDetail, Reviews, About, Contacts, NotFound) по категориям:
  цвет, типографика, композиция, иерархия, компоненты, анимации, UX (перегруз/пустоты).
  По коду + локальный запуск со скриншотами. Результат — документ с вердиктами.
- **Этап B — дизайн-система:** markdown-концепция в docs/ + живой HTML-стайлгайд артефактом.
  Обязательный состав: **полные Design Tokens** (палитра-роли Primary…Disabled, типографическая
  шкала Display…Label, spacing по 8pt, радиусы, тени, бордеры, сетка, состояния компонентов,
  принципы анимации); **конкурс display-шрифта кириллицы** (3+ кандидата рядом);
  **две концепции Light-first и Dark-first** (переключатель в стайлгайде); UI-kit;
  3 варианта фирменного фона; **Hero как уникальный фирменный актив** (кандидаты: орбитальная
  система, пиксельный роспад знака TB, карта Казахстана из точек) → Утверждение заказчиком.
- **Этап C — имплементация** (только после утверждения B): по этапам — токены → айдентика →
  графика → страницы. Проверка: `npm run build` + визуальный обход, сверка с бренд-буком.

## Бренд-бук — суть

**Фирменные цвета:**

| Цвет | HEX |
|------|-----|
| Purple | `#5B21B6` |
| Violet / Magenta | `#D946EF` |
| Orange | `#F97316` |
| Yellow | `#FACC15` |
| Blue | `#2563EB` |

- **Фирменный градиент** (ядро стиля): фиолетовый → магента → оранжевый по диагонали.
  Линии-разделители, кнопки, акценты, обводка иконок. Доп. оттенки: тинты 80/60/40/20%.
- **Шрифты:** `Michroma` — лого-блок и display (Latin-only!). `Inter` — текст.
- **Тёмный фон бренда:** глубокий near-black indigo (НЕ синий navy).
- **Фирменная графика:** орбиты/частицы (стр. 11–12), волновые линии из точек (стр. 13–14),
  круговые «process»-кольца (стр. 15), точечный градиентный паттерн (стр. 16), изометрические
  tech-иллюстрации с градиентной обводкой (стр. 17–18, 28), текстуры (стр. 19),
  линейные иконки с градиентной обводкой (стр. 20), карта Казахстана из точек (стр. 33).
- **Стилеобразующий элемент с бейджей:** восходящая градиентная диагональ 2pt (стр. 26–27).
- **Тон/слоганы:** «Системный подход к вашему успеху», «Архитекторы вашего роста»,
  «Ваш бизнес. Наша система. Ваш успех.», «Системы, которые работают на ваш рост»,
  «Создаём будущее Казахстана». Гео-акцент — **Казахстан**.

## Текущее состояние сайта (что менять)

- Палитра `tailwind.config.js`: `navy #0B1F3A` + `accent #2D9CDB` (голубой) — мимо бренда.
- Шрифт — только `Inter` (Google Fonts CDN в `index.html`), Michroma нет.
- Логотип — текстовый бейдж «TB» (`Navbar.jsx`), favicon текстовый — настоящего лого нет.
- Кнопки/ссылки — плоский голубой (`index.css`: `.btn-primary`, `.glass`), градиента нет.
- Иконки услуг — эмодзи 📦👥📞 (`ServicesGrid.jsx`).
- Hero — голубые blur-пятна + glass-карточки (`Hero.jsx`) — из «запрещённого» списка брифа.

## Ключевые находки

- ⚠️ **В PDF нет векторного логотипа** — страницы это плоские растры (~1491×1055 px).
- ✅ Извлечённый логотип-локап чистый ~875×205 px — годен для навбара/футера (retina до ~180 px).
  Версия знака на тёмном — стр. 3 PDF. Знак для favicon/hero пересобрать как SVG.
- ⚠️ **Michroma не поддерживает кириллицу** (Latin-only). В бренд-буке кириллица набрана другим
  техно-шрифтом. Решение: Michroma латиница/цифры, русские заголовки — гротеск.
- Инструменты: PDF рендерится Python `PyMuPDF (fitz)` + `Pillow` (установлены);
  текстового слоя в PDF нет (`pdftotext` бесполезен).

## Технический контекст проекта

- Монорепо: `client/` (React 19 + Vite + Tailwind + Framer Motion, порт 5173),
  `admin/` (5174), `server/` (Express + MongoDB, 5000), `nginx/`, `docker-compose.yml`.
- Прод: VPS `tbgroup.kz`, Docker Compose из GitHub (ветка `main`).
- Часть контента управляется из админки (баннеры/страницы через `SettingsContext`),
  часть — дефолты в компонентах (`defaultPages.js`, `serviceContent.js`).
- Бизнес-логику и структуру страниц НЕ менять — только визуальная система.
