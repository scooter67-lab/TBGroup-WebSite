## Концепция: «Системная точность», правило 90/10

~90% поверхности — нейтральные «бумага/чернила» с фиолетовым подтоном, инженерная сетка,
воздух. Бренд — в ~10%: градиент G1, пиксельный роспад, орбиты, Michroma-лейблы, цифры.
Каждый элемент трассируется к странице бренд-бука (диагональ 2pt — бейджи стр. 26–27;
точки — паттерн стр. 16; орбиты — стр. 11–12; Ink #0E0A1F — фон стр. 3).

### Типографика
- **Michroma** (latin-only): лейблы-эйбра 10–11px CAPS +0.16em, цифры статистики 22→28px.
  Никогда: кириллица, текст длиннее 3–4 слов.
- **Display-шрифт кириллицы — конкурс** (выбор за заказчиком, специмены в стайлгайде):
  1. **Unbounded 600 — рекомендация** (техно-геометрия = родня Michroma; беречь от длинных строк)
  2. Onest 800 — запасной (сдержаннее, вектор Linear/Vercel)
  3. Manrope 800 (мягче, слабее техно-характер)
  4. Inter 800 tight (безопасно, но риск шаблонности)
- Шкала: Display 40→64/1.05 · H1 32→46/1.1 · H2 24→32/1.18 (display-шрифт, 600);
  H3 18→20/700 · Subtitle 17→19/500 · Body 16–16.5/1.6 · Body-S 14 · Caption 12.5–13 ·
  Button 14–15/600 (Inter). Display-шрифт только на 3 верхних уровнях.
- Все шрифты self-host: `client/public/fonts/*.woff2`, сабсеты latin+cyrillic.

### Пространство и форма
- 8pt: 4/8/12/16/24/32/48/64/96/128. Секции 96–128 десктоп / 64 мобайл.
- Радиусы: 8 бейджи · 12 кнопки/поля · 16 карточки · 24 hero-панели. Пилюли — только бейджи.
- Тени: sm/md/lg двухслойные тихие; несут состояние (hover, модалка), не иерархию.
- Границы: 1px базовая, 1.5px интерактив, 2px градиент — **восходящая диагональ** 9–14°
  (hover карточек, углы панелей, hero).
- Контейнер 1200px, 12 колонок, желоб 24. Текст ≤ 65ch.

## Компоненты (ключевые правила)
- **Кнопки:** Primary — заливка G1, hover: светлый сдвиг градиента + подъём 1px + цветная
  тень; **одна градиентная кнопка на экран**. Secondary — рамка 1.5px. Ghost — градиентное
  подчёркивание вырастает слева. Размеры S/M/L.
- **Поля:** Surface-фон, рамка 1.5px, focus: magenta-рамка + кольцо 18%; error `#E5484D`
  с текстом-подсказкой «как исправить».
- **Карточки:** Card-фон, 1px рамка, radius 16; hover: подъём 3px + тень md + появляется
  градиентная диагональ. Иконка 40–44px с градиентной обводкой. Никакого glass.
- **Пустые состояния — обязательны** (на проде 0 отзывов, 1 кейс): точечный кластер +
  заголовок + действие. Фильтры на /cases — только при ≥ 6 записях.
- Табы: активная — градиентный подчерк. Бейджи: tech (Michroma CAPS), gradient-border, dot.
- FAQ: карточка + плюс→крест поворотом 45°, native `<details>`.

## Иконография
Сетка 24px, штрих 1.8px, скругления, обводка — общий SVG-градиент G1 (одно направление 135°
на всём сайте). База Lucide + перерисовка ключевых иконок услуг. Эмодзи запрещены.

## Фирменные фоны
- **B1 Пиксельная волна** (паттерн стр. 16 с затуханием) — светлые секции, шапки страниц.
- **B2 Орбитальная система** (стр. 11–12) — hero, футер, тёмные CTA-панели.
- **B3 Цифровая сетка** (44px + диагональ 2pt + светящийся узел) — тех. секции, 404.
Не совмещать два фона в одной секции.

## Hero
Живой макет — в стайлгайде. Рекомендация **A «Орбитальная система»**: ядро из «пикселей»
знака + орбиты с узлами-сервисами; Michroma-лейбл `TB GROUP · КАЗАХСТАН`; статистика
со счётчиками поверх нижней кромки панели; восходящая диагональ.
Альтернативы: B «Пиксельный роспад» (нужен безупречный вектор знака), C «Карта Казахстана»
(лучше для «О компании»/CTA). В Light-концепции hero — тёмная Ink-панель (главный контраст
сайта), в Dark — сливается с фоном.

## Движение
`dur-1 150ms · dur-2 250ms · dur-3 600ms (счётчики 1.2s) · ease cubic-bezier(.22,.61,.36,1)`
Reveal: fade + 10px, каскад 60ms, **только opacity/transform, контент виден без JS**
(урок аудита). Декоративное движение только в hero/фонах (орбиты 80–120s linear).
`prefers-reduced-motion`: декор стоп, reveal мгновенный.

## Responsive
- <640: 1 колонка, статистика 2×2, кнопки 100%, секции 64px, hero-орбита под текст с маской.
- 640–1024: сетки ×2, компактное меню.
- 1024–1440: полная сетка. >1440: контейнер не растёт, фоны — до краёв.
- Обязательная проверка 390px (на проде сейчас overflow-баг).

## Улучшения v1.1 (по правкам заказчика, утверждены)

1. **Hero v2 «инженерная система»** — сцена в ~1.8× панели, уходит за края (эффект
   продолжения за экраном); ядро-«роспад» со свечением; узлы-чипы интеграций
   `MOYSKLAD · BITRIX24 · SIP · 1C · API` (Michroma, латиница) на подложках; коннекторы
   с узловыми изломами (квадраты 4px); анимированный «пульс данных» по градиентной линии
   (dashflow); инженерные метки-перекрестия; trust-бейджи партнёрств под CTA.
   На мобиле сцена уходит в фон с opacity .32.
2. **Фирменный «срез TB» у карточек** — постоянный элемент бренда: верхний правый угол
   срезан 45° (22px, `clip-path`), по срезу градиентный кант 2px (G1); у featured-карточек
   пиксельный кластер 3 точки у среза. Геометрия — из срезов знака B логотипа.
   На hover — подъём + восходящая диагональ (как раньше).
3. **Библиотека декора** (усиление графики бренд-бука): кольца процессов (стр. 15),
   точечные волны (стр. 13–14), пиксельные кластеры (лого), инженерные метки (стр. 12).
   B1-фон дополнен волновой линией из точек.
4. **Чек-лист «крупной технологической компании»** = критерии приёмки этапа C:
   глубина hero за границами блока; партнёрские статусы на первом экране; реальные
   метрики в Michroma со счётчиками; единая иконография без эмодзи; спроектированные
   пустые состояния; ритм 96–128px и «срез TB» везде.

## Утверждённые решения (история)
1. Display-шрифт кириллицы: **Unbounded** (Onest — запасной).
2. Концепция: **Dark-first** (основная тема сайта; light сохраняется как вторая).
3. Hero: **A «Орбитальная система» v2**.
